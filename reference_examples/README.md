# reference_examples —— 参考专利（仅供学习格式，严禁迁移内容）

本目录用于放置参考专利文件（docx/pdf/txt 等），供本 skill 学习：
- 中国发明专利的**格式与章节结构**；
- **八股句式 / 固定表达 / 套话**；
- 专利**语言风格**（专利语言而非论文语言）；
- 权利要求与说明书的**对应关系与展开方式**。

## 绝对红线（最重要）
参考专利**只能**用于上面四类"形式层面"的学习。**严禁**把参考专利中的任何实质内容迁移到当前专利：
- ❌ 技术对象 / 行业场景
- ❌ 变量名称 / 模型结构 / 公式
- ❌ 约束条件 / 设备部件 / 步骤内容
- ❌ 技术领域默认值

> 本 skill 是**通用**专利撰写工具。参考专利写的是什么行业、什么方法，与当前任务无关。
> 当前专利的全部技术内容，必须来自用户本次提供的技术资料。

## 自检
写每一句前自问："这句话的技术内容来自用户本次资料，还是来自参考专利？"
凡来自参考专利的实质内容，一律删除。

## 放置方式
直接把参考专利文件拷入本目录即可。若为 docx/pdf，可先转成文本以便提取句式（不要提取技术内容）。
