- 从属权利要求必须引用在前权利要求，用"所述"承接术语。

# 权利要求书模板

## 一、方法类

### 独立权利要求
```
1. 一种XXX方法，其特征在于，包括以下步骤：
   步骤一：……；
   步骤二：……；
   步骤三：……；
   步骤N：……。
```

### 从属权利要求
```
2. 根据权利要求1所述的一种XXX方法，其特征在于，步骤一中，……。
3. 根据权利要求1所述的一种XXX方法，其特征在于，步骤二中，……。
4. 根据权利要求1所述的一种XXX方法，其特征在于，所述……包括……。
5. 根据权利要求2所述的一种XXX方法，其特征在于，……。
```

## 二、系统类

### 独立权利要求
```
1. 一种XXX系统，其特征在于，包括：
   数据获取模块，用于……；
   处理模块，用于……；
   判断模块，用于……；
   输出模块，用于……。
```

### 从属权利要求
```
2. 根据权利要求1所述的一种XXX系统，其特征在于，所述处理模块包括……。
3. 根据权利要求1所述的一种XXX系统，其特征在于，所述判断模块用于……。
```

## 三、装置类

### 独立权利要求
```
1. 一种XXX装置，其特征在于，包括：
   第一部件；
   第二部件；
   连接部件；
   控制单元；
   其中，……。
```

### 从属权利要求
```
2. 根据权利要求1所述的一种XXX装置，其特征在于，所述第一部件……。
3. 根据权利要求1所述的一种XXX装置，其特征在于，所述连接部件……。
```

## 四、设备类

### 独立权利要求
```
1. 一种XXX设备，其特征在于，包括存储器和处理器；
   所述存储器存储有计算机程序；
   所述处理器执行所述计算机程序时实现如权利要求1至N中任一项所述的XXX方法的步骤。
```
（说明：设备类常以"存储器+处理器"形式承载方法权利要求。具体引用编号按实际方法权项数量调整。）

## 五、计算机可读存储介质类

### 独立权利要求
```
1. 一种计算机可读存储介质，其上存储有计算机程序，其特征在于，所述计算机程序被处理器执行时实现如权利要求1至N中任一项所述的XXX方法的步骤。
```

---
> 提示：一份申请可同时包含方法类 + 系统/装置类 + 设备类 + 存储介质类，构成多个独立权利要求；务必保证各独立权利要求主题与说明书一致、彼此对应。
