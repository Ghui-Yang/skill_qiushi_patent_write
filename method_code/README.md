# method_code —— 用户方法代码与数据（生成真实效果图用）

本目录用于存放**用户提供的方法代码、测试数据、运行入口与依赖说明**。
它是生成"真实仿真效果图"的唯一数据来源。**没有这里的真实代码/数据，就不得画效果图**（见 SKILL.md 第十一节）。

## 子目录
- `src/`：方法源码（你的算法/模型/控制器/工艺计算等运行代码）。
- `data/`：测试数据 / 输入样例。
- `requirements.txt`：运行所需 Python 依赖。

代码运行后产出的结果（CSV、xlsx、log 等）不要写入本 skill 目录；应写入当前工作目录的 `outputs/run_results/`，供 `figure_generation/` 绘图或供专利草稿引用。

## 使用流程
1. 把方法代码放入 `src/`，数据放入 `data/`。
2. 安装依赖：`pip install -r requirements.txt`。
3. 运行你的方法，把可体现技术效果的指标导出为 CSV 到当前工作目录的 `outputs/run_results/`：
   - 第一列为横轴（迭代次数/时间步/样本编号等）；
   - 其余每列一条曲线，列名即图例（如"本发明方法""对比方法""传统方法"）。
4. 用 `../figure_generation/generate_effect_figures.py` 把 `outputs/run_results/*.csv` 绘成黑白效果图，图片输出到当前工作目录的 `outputs/figures/`。

## 红线（严禁）
- 不得凭空生成仿真结果；
- 不得伪造实验数据；
- 不得在无代码/无数据时画效果曲线；
- 不得把示意图冒充真实仿真图；
- 不得把随机数描述为真实结果。

## 无代码时的标准处置
若本目录无可运行代码或数据，应向用户说明：

> 当前未发现可运行的方法代码或示例数据，因此无法生成真实仿真效果图。可以先生成附图设计方案，待用户提供代码和数据后再生成真实效果图。

（流程图/结构图/示意图等设计性附图不受此限，可直接绘制。）
